# Silent Voyagers - Public Assets Directory

This directory stores 3D meshes, archival photographic imagery, audio telemetry recordings, and orbital satellite overlays utilized across the Silent Voyagers application.

## Directory Structure
- `public/assets/models/`: GLB / glTF 3D models of NASA exploration hardware.
  - `mer-opportunity.glb`: Source: [NASA 3D Models: MER Opportunity](https://data.nasa.gov/dataset/nasa-3d-models-mer-opportunity)
  - `mer-spirit.glb`: MER-A twin geometry with broken front-wheel texture
  - `insight-lander.glb`: InSight Lander with deployed UltraFlex arrays and SEIS dome
  - `apollo-11-descent.glb`: Apollo 11 Lunar Module (LM-5) Descent Stage
- `public/assets/relics/`: Curated imagery from NASA JPL Photojournal, Apollo Lunar Surface Journal, and HiRISE/LROC orbiter archives.
- `public/assets/audio/`: Synthesized and sonified audio files converted from InSight SEIS broadband data and Deep Space Network carrier wave signals.
